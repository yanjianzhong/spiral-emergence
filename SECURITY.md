# Security Policy

## Supported versions

Security fixes are provided for the latest published version.

## Reporting a vulnerability

This project is a numerical research codebase for tensor-network computations. It does not process untrusted input, execute external code, or handle authentication. If you identify a security-relevant issue, please open a public issue or contact the maintainer via GitHub.

## Security boundary

This software runs entirely in the user's local Python environment with no network 
services, no privilege escalation, and no parsing of untrusted data formats.
